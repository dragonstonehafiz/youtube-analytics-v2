Reader and writer

This page explains the functions in database/reader.py and database/writer.py.

Reader

FunctionWhat it does
selectReturns rows from one table
select_oneReturns the first matching row from one table, or None
fetchRuns a prepared query and returns one data class per row
fetch_joinedRuns a prepared query that joins tables and returns each row split into data classes and totals
scalarReturns the MIN, MAX, SUM or COUNT of one column in one table
fetch_scalarRuns a prepared query and returns its single value
group_bySplits rows that were already read into lists by one field
connectOpens one connection for several reads

SELECT

select(Model, fields, where=, order_by=, limit=, offset=)

Returns the rows of one table that match where, reading only the listed columns.

reader.select(Comment, ("id",), where=[("video_id", "=", "v-1")])
# [Comment(id="c-1"), Comment(id="c-2")]

select_one(Model, fields, where=, order_by=)

Returns the first matching row, or None when nothing matches.

reader.select_one(FxRate, ("date", "usd_to_sgd"), order_by=("-date",))
# FxRate(date="2024-06-01", usd_to_sgd=1.35)

fetch(Model, query)

Runs a prepared query and returns one data class per row. Every column the query returns must be a field of that class.

reader.fetch(SearchTerm, query)
# [SearchTerm(search_term="cats", views=17), SearchTerm(search_term="dogs", views=9)]

fetch_joined(query, models, values)

Runs a prepared query that joins tables. Each row comes back with one data class per table, plus any calculated totals in row.values.

rows = reader.fetch_joined(query, (Video,), ("period_views",))
rows[0][Video]    # Video(id="v-1", title="Alpha Video")
rows[0].values    # {"period_views": 120}

Aggregates

scalar(Model, aggregate, column, where=)

Returns one value: the MIN, MAX, SUM or COUNT of a column over the matching rows.

reader.scalar(Video, "MIN", "published_at", where=[("own", "=", True)])
# "2019-03-02T10:00:00Z"

fetch_scalar(query)

Runs a prepared query and returns the first column of its first row.

reader.fetch_scalar(count_query)
# 342

GROUP BY

group_by(rows, field, limit=)

Splits rows that were already read into lists by one field, keeping their order. limit keeps only the first rows of each list.

reader.group_by(rows, (VideoTrafficSource, "traffic_source_type"), limit=10)
# {"SEARCH": [first 10 rows], "SUGGESTED": [first 10 rows]}

Connections

connect()

Opens one connection, passed to each read as conn=, and closes it at the end of the block.

with reader.connect() as conn:
    total = reader.fetch_scalar(count_query, conn=conn)
    rows = reader.fetch_joined(page_query, (Video,), conn=conn)

Writer

FunctionWhat it does
writeUpdates the row with the same key, or inserts it
write_manyDoes the same for a batch of rows, all or none
updateChanges every row matching a condition
deleteDeletes every row matching a condition

INSERT or UPDATE

write(row, returning=)

Updates the row with the same key, or inserts it if there is none. Fields set to None are not written. returning gives back fields as stored, such as an ID SQLite generated.

writer.write(Video(id="v-1", title="Alpha Video", view_count=120))
# 1

writer.write(SyncRun(batch_id="b-1", sync_type="videos", status="running", started_at=now()), returning=("id",))
# SyncRun(id=42)

write_many(rows)

Writes a batch of rows of one class the same way as write, in one transaction: if one row fails, none are saved.

writer.write_many([SearchTerm(video_id="v-1", month="2024-03", search_term="cats", views=17), ...])
# 12

UPDATE

update(row, where=)

Sets the row's fields on every row matching where and returns how many changed. It never inserts.

writer.update(SyncRun(status="incomplete"), where=[("status", "=", "running")])
# 2

DELETE

delete(Model, where=)

Deletes every row matching where and returns how many were deleted. A condition is required.

writer.delete(Video, where=[("own", "=", True), ("id", "NOT IN", ["v-1", "v-2"])])
# 1
