Frontend code

Optional query parameters in api.ts

×14

Wrappers spell out each optional filter as a spread so empty values are left out, even though buildUrl already skips empty values.

Where
api.ts: start_date/end_date spread in 14 wrappers, title in 8, content_type and privacy_status in 7. Most playlist wrappers also mirror a channel wrapper.
Differs
Which filters a wrapper accepts. Newer wrappers take a query object instead.
...(startDate && { start_date: startDate }), ...(endDate && { end_date: endDate }),
...(contentType && { content_type: contentType }), ...(privacyStatus && { privacy_status: privacyStatus })
