Backend: sync

One connection and commit per row

per row

Each writer.write() call opens its own connection and commits.

Where
Every streamed row in sync/stages.py; monthly insights already batch per month.
Cost
A commit per row instead of per batch, each waiting for the write lock.

Backend: API reads

Substring title search

per filtered request

The title filter is v.title LIKE '%…%' OR v.id LIKE '%…%'.

Where
11 reads in backend/database/reports/, all through video_conditions()
Cost
A leading % cannot use an index, so every video row is scanned. Small at the current table size.

Whole-database scan for storage statistics

per Sync page open

/sync/database reads every page through dbstat and runs COUNT(*) on every table.

Where
database/reports/storage.py, called by DatabaseOverview each time the Sync page opens
Cost
Starts a Python process and reads the whole database file per request, so the time grows with the database size.

Frontend

Two status pollers on the Sync page

every 5 s

The top navigation and the Sync page each request /sync/status every 5 seconds.

Where
components/SyncStatus.tsx, pages/Sync.tsx
Cost
Two requests per interval on Sync; the top navigation's poll runs on every page whether or not a sync is running.

Superseded requests are not cancelled

per filter change

Old responses are ignored through an active flag, but no request is aborted.

Where
Every data effect; there is no AbortController in frontend/src
Cost
Each filter, date or tab change leaves the previous requests running to completion on the backend.
